# WebFruitUI

This is a template for a responsive web application with an interface reminiscent of a famously fruit-based operating system. 

https://github.com/user-attachments/assets/738d5b9f-9de4-40fe-ab0c-acad1059e834

# Features

- Responsive design.
- Dark & Light modes.
- Working Dock with animation and app activity indicator.
- Working window movement (in desktop mode).
- Working window decorations (close, maximise, double-click on title bar).

# Based on

- Wallpapers based on [Javier Ocasio](https://4kwallpapers.com/gradients/waves-macos-big-sur-colorful-5k-4992.html).
- [macOS Dock](https://codepen.io/vihanga/pen/gOmXvRr).

- [Bootstrap Icons](https://icons.getbootstrap.com).
